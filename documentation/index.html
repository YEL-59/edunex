Edunex - Next.js Education LMS Template

Thank you for purchasing Edunex! Edunex is an ultra-premium, modern, and high-performance Education LMS and Online Course template built with Next.js (App Router), TypeScript, and Tailwind CSS.

ThemeForest Quality Standards: This template has been created following Envato's strict TypeScript and Next.js guidelines with zero lint errors and zero build warnings.

2. System Requirements

  • Node.js: v18.18.0 or newer (v20+ recommended)
  • npm: v9.0.0 or newer (or pnpm / yarn)
  • Code Editor: Visual Studio Code, Cursor, or WebStorm

3. Getting Started

Follow these steps to get the development environment running locally:

Step 1: Extract and Open

Extract the downloaded ZIP package and open the edunex folder in your terminal or IDE.

Step 2: Install Dependencies

npm install

Step 3: Run Development Server

npm run dev

Now open http://localhost:3000 in your web browser.

5. Customizing Content & Data

All content is decoupled from components and stored in typed TypeScript files inside src/data/. You do not need to hunt through JSX to edit text or course details!

Data File Contents
src/data/navigation.ts Main menu navigation, dropdown items, and links
src/data/courses.ts Course titles, badges, instructor info, lessons, prices, filter tabs
src/data/categories.ts 8 category cards, colors, course count, and links
src/data/instructors.ts Instructor profiles, ratings, course counts, students count
src/data/testimonials.ts Student feedback quotes, reviewer names, designations, avatars
src/data/events.ts Upcoming events, locations, timings, dates
src/data/counters.ts Stat targets, numbers, and suffixes
src/data/blogs.ts Blog articles, thumbnails, categories, dates

6. Fonts & Icons

Fonts: We use Google Fonts (Manrope for body and Urbanist for headings) configured via next/font/google in src/app/layout.tsx. This eliminates layout shifts and improves Google PageSpeed scores.

Icons: Authentic edunex-icons are included with font files in public/assets/fonts/. Simply use <i className="tji-*"></i>.

7. Styling & Colors

Colors are controlled via CSS custom properties in src/styles/main.css and Tailwind configuration. Primary colors:

  • --tj-color-theme-primary: #723ec3 (Signature Purple)
  • --tj-color-heading-primary: #272f54 (Dark Blue)
  • --tj-color-text-body: #434966 (Muted Text)

8. Production & Deployment

To create an optimized production build:

npm run build
npm run start

This project is 100% compatible with one-click deployment on Vercel, Netlify, or any Node.js hosting platform.
